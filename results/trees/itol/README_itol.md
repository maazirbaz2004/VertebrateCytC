# iTOL Export Instructions

1. Open https://itol.embl.de/upload.cgi and upload `cytc_ml_rooted.nwk`.
2. Drag and drop `itol_colorstrip_clade.txt` and `itol_labels_common_names.txt` onto the tree canvas.
3. In Control Panel -> Advanced, enable Bootstrap / metadata display as text (values represent IQ-TREE UFBoot %).
4. Verify rooting on *Saccharomyces cerevisiae*, then export as SVG/PDF via the Export tab.
